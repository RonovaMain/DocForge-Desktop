# DocForge для ПК

Просмотрщик и редактор офисных файлов для Windows и Linux — настольная версия [DocForge для Android](https://github.com/RonovaMain/DocForge).
Работает полностью локально, без интернета.

| Формат | Просмотр | Правка текста |
|---|---|---|
| **DOCX** (Word) | да | да |
| **XLSX** (Excel) | да | да (значения и формулы) |
| **PPTX** (PowerPoint) | да | да |
| **ODT / ODS / ODP** (LibreOffice) | да | да |
| **PDF** | да | нет |

## Возможности

- Просмотр и правка: режим правки (Ctrl+E), клик по абзацу, ячейке или тексту слайда; «Сохранить» (Ctrl+S) и «Сохранить как…».
  Меняется только нужный текст, оформление, картинки и остальная структура файла сохраняются.
- Нумерация страниц у PDF и презентаций, переход на страницу (Ctrl+G), масштаб (Ctrl +/−/0, Ctrl+колесо), тёмная тема документа (Ctrl+D).
- Поиск (Ctrl+F): в Word, Excel и LibreOffice — с подсветкой, в PDF — по тексту страниц с переходом на страницу.
- Сохранение картинок: правая кнопка по картинке; «Сохранить все картинки (ZIP)»; страница PDF как изображение.
- Режим презентации (F5 — с начала, Shift+F5 — с текущей) для PDF, PPTX, ODP: стрелки, пробел, колесо, клик слева/справа; Esc — выход.
- Экспорт документов Office в PDF.
- **Печать** (Ctrl+P): выбор страниц (все / текущая / диапазон `1-3, 5, 8-`), бумага A4/A5/Letter/Legal, ориентация, поля, копии,
  ручная двусторонняя печать («пачкой» или «по листу» — программа ждёт, пока вы перевернёте бумагу).
  Два способа, как в Android-версии:
  - **Системная** — через драйвер принтера Windows / CUPS, как в любых других программах.
  - **Встроенная** — DocForge сам готовит данные и отправляет их принтеру: PCL 5, PostScript, PDF напрямую или фильтры
    **foo2zjs, foo2xqx, foo2qpdl, foo2slx, foo2lava** (для принтеров «с хост-драйвером», которые не понимают PCL).
    Драйвер подбирается автоматически по модели принтера и меняется вручную. HP LaserJet 1010/1012/1015 печатаются встроенным PCL 5.
    Принтерам HP на ZjStream/XQX нужна прошивка (файл `.dl` из пакета foo2zjs): выберите её в окне печати, DocForge хранит её и
    отправляет в принтер перед печатью. Саму прошивку программа не содержит.
- Окно можно оформить светлым, тёмным или как в системе. Файл можно перетащить в окно или открыть через «Открыть с помощью».

## Чего пока нет по сравнению с Android-версией

- Рисование поверх страниц (ручка, маркер, ластик) и вшивание пометок в PDF.
- Сохранение картинок, встроенных в PDF (есть сохранение страницы как изображения).
- Печать напрямую по USB минуя систему (libusb): сейчас данные идут через очередь принтера Windows / CUPS.
- Чтение IEEE 1284 Device ID у принтера: модель берётся из системы (драйвер/адрес устройства), языки принтера не опрашиваются.
- PDF с паролем.
